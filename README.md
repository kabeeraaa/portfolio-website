# Kabir Dubey Portfolio

A React and TypeScript portfolio with two views. The main view presents education, experience, and selected projects. The game view presents the same project list through an interactive menu.

## Run locally

Use Node.js 22.12 or later on the 22.x line, or Node.js 24.

```sh
npm ci
npm run dev
```

Use the **Main** and **Game** buttons to switch views. Run `npm run build` to check TypeScript and build the site into `dist/`.

## Featured repositories

- [Kanban Board](https://github.com/kabeeraaa/kanban-board)
- [Bake My Cake](https://github.com/kabeeraaa/bake-my-cake)
